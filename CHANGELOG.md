# Changelog

All notable changes to this project are documented in this file.

The project follows Semantic Versioning.

## [1.0.0] - 2026-09-24

### Added

- Node.js application packaging with npm.
- Python Django application packaging with setuptools and `setup.py`.
- Python package configuration using `pyproject.toml`.
- Java application packaging with Maven.
- Node.js dependency audit.
- Python dependency audit.
- Java dependency tree and security audit.
- Staging verification for Node.js, Python, and Java packages.
- SHA-256 checksums for packaged artifacts.
- Automated artifact integrity verification.
- Automated artifact validation script.
- Software artifacts for Node.js, Python, and Java.
